# 3D Raytracer for CS488 Final Project

## Main features:
- Real-time Area lights with [Linearly Transformed Cosines](https://dl.acm.org/doi/10.1145/2897824.2925895)
- Texture Anti-Aliasing with Mip-mapping via [Ray Differentials](https://graphics.stanford.edu/papers/trd/)
- Surface Area Heuristic Bounding Volumes Hierarchy (SAH-BVH) for efficient scene-ray intersections
